# Portfolio — วิธีใช้หลังบ้าน

## เปิดหลังบ้าน
1. ดับเบิลคลิก **`start-admin.bat`** (ต้องมี Python ในเครื่อง)
2. เบราว์เซอร์จะเปิดหน้า **http://localhost:5500/admin/** ให้เอง
3. แก้ไขข้อมูล แล้วกด **บันทึก** มุมขวาบน (หรือกด Ctrl+S)
4. กด **ดูเว็บ ↗** เพื่อดูผลลัพธ์
5. ใช้งานเสร็จแล้วให้ปิดหน้าต่างดำ (server)

## หลังบ้านทำอะไรได้บ้าง
| เมนู | ทำอะไรได้ |
|---|---|
| 🎬 ผลงานวิดีโอ | วางลิงก์ YouTube แล้วระบบดึงชื่อคลิปกับภาพปกให้เอง · ลิงก์ Facebook/TikTok ให้อัปโหลดภาพปกเอง · ติดดาวผลงานเด่น · จัดหมวด · เรียงลำดับ |
| 🎨 ผลงานกราฟิก | ลากรูปมาวางได้ทีละหลายรูป (ระบบย่อขนาดให้) · ตั้งชื่อ · เรียงลำดับ · ลบ |
| 💼 Work History | เพิ่ม/แก้ไขบริษัท ตำแหน่ง ระยะเวลา รายละเอียด โลโก้ และลิงก์ |
| 👤 ข้อมูลส่วนตัว | ชื่อ คำคม ข้อความ About และแถบตัวอักษรวิ่ง |
| 🔗 ติดต่อ & เครื่องมือ | ช่องทางติดต่อ และโปรแกรมที่ใช้ |

- ตัวเลขสถิติบนหน้าเว็บคำนวณให้อัตโนมัติ
- ทุกครั้งที่กดบันทึก ระบบจะสำรองไฟล์เก่าไว้ในโฟลเดอร์ `backups/`
- เวลาลบผลงานในหลังบ้าน ไฟล์รูปจะยังอยู่ในโฟลเดอร์ `assets/` ถ้าอยากประหยัดพื้นที่ต้องลบเอง

## เอาขึ้นเว็บจริง
อัปโหลดไฟล์เหล่านี้ขึ้นโฮสต์ static ที่ไหนก็ได้ เช่น GitHub Pages, Netlify หรือ Vercel:
`index.html`, `data.json`, `assets/`

ไม่ต้องอัปโหลด `server.py`, `start-admin.bat`, `admin/` และ `backups/` เพราะหลังบ้านใช้ได้เฉพาะบนเครื่องตัวเอง
ถ้ามีการแก้ไขข้อมูล ให้แก้บนเครื่องก่อน แล้วค่อยอัปโหลด `data.json` และ `assets/` ขึ้นไปใหม่
